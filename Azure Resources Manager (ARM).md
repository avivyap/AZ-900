ARM es el servicio de implementación y administración de Azure. 

Proporciona una capa de administración que permite crear, actualizar y eliminar recursos en una suscripción de Azure. 

Puede usar características de administración, como el control de acceso, los bloqueos de recursos y las etiquetas de recursos, para proteger y organizar los recursos después de la implementación.

### Plantillas 

ARM permite gestionar y orquestar recursos en Azure de manera centralizada

Utiliza plantillas declarativas en JSON para describir recursos y configuración

Facilita la creación, actualización y eliminación de recursos de forma controlada 

Si importamos una plantilla en azure, NO se despliega el servicio automáticamente, sino que se almacena y después tienes que desplegarlo
